# hammockai.site

Landing page of [Hammock AI](https://github.com/hammockai), live at **https://hammockai.site**.

Static and sovereign: HTML5 + hand-written CSS + vanilla JS. No frameworks, no CDN, no build step, zero telemetry.

| File | What it is |
|---|---|
| `index.html` · `style.css` · `script.js` | The live site |
| `brief/` | Client brief form (runs in the browser, nothing is sent anywhere) |
| `assets/` | Logo and images |
| `AGENTS.md` | Rules for the AI coding agent working on this repo |

**Preview locally:** open `index.html`, or run `npx http-server . -p 8080`.
**Deploy:** push to `main` → GitHub Pages publishes it.

The earlier Tailwind CLI version lives in the branch [`archive/tailwind-pipeline`](https://github.com/hammockai/hammockai.site/tree/archive/tailwind-pipeline).
